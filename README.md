# ☕ Maratona Java

Repositório com o código que produzo durante a
[Maratona Java - Virado no Jiraya](https://www.youtube.com/playlist?list=PL62G310vn6nFIsOCC0H-C2infYgwm8SWW),
do DevDojo.

## 🎯 Objetivo

Aprender Java do zero, com foco em boas práticas, Clean Code e desenvolvimento backend.

## 🛠️ Tecnologias

- Java (versão: 17)
- IDE: IntelliJ IDEA
- Git/GitHub
